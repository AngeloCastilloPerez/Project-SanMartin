# Project-SanMartin
Proyecto de consultoría BI/Data para San Martín Contratistas Generales S.A, empresa de operaciones mineras en Perú. Se rediseñó completamente el modelo de datos Power BI existente y se construyó una nueva arquitectura de datos sobre Microsoft Fabric, reemplazando procesos manuales con Excel por pipelines automatizados conectados directamente a SAP.
